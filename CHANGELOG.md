# Change Log

All notable changes to the "branch-reviewer" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.2]

- Approving an unsigned commit signs it first, replaying the rest of the
  branch onto the signed commit before the base is fast-forwarded.
- Changed files and folders use clearly green (added) and yellow
  (modified) label colors in every theme.

## [0.0.1]

- Initial release: commit-by-commit branch review with approve, reword,
  edit, quit and abort, a Files Changed explorer with change colors and
  filtering, gutter change marks, conflict handling, autostash, outside
  change detection, status bar progress and logging.
